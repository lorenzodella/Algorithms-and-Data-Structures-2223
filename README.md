# Prova Finale API 2022-2023 - Politecnico di Milano

Final project for the **Algorithms and Data Structures** (*Algoritmi e Principi dell'Informatica - API*) course at **Politecnico di Milano** (A.Y. 2022-2023).

**Final Grade:** **30L / 30 with honors (30 e Lode)**

---

## 📌 Project Overview

The project requires managing a highway modeled as an ordered sequence of service stations. Each station is uniquely identified by its distance from the beginning of the highway (in km) and holds a fleet of electric vehicles, each characterized by its maximum battery autonomy (range in km).

The system supports the following real-time operations efficiently:
- **`aggiungi-stazione`**: Add a new service station with its initial car fleet.
- **`demolisci-stazione`**: Remove an existing station.
- **`aggiungi-auto`**: Add a vehicle with a specific autonomy to a station.
- **`rottama-auto`**: Remove a vehicle from a station.
- **`pianifica-percorso`**: Plan the optimal path between two stations (forward or backward) minimizing the number of stops, with deterministic tie-breaking rules favoring stations closer to the start.

### Implementation Details
- **Language**: Standard C
- **Data Structures**: Self-balancing search trees / BST for stations, max-heaps for vehicle fleets, and BFS / dynamic programming with backtracing for optimal path planning under strict time and memory constraints.
